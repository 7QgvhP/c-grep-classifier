# 0003. パーサーの WASM をバイナリとして直接読み込む

- ステータス: Accepted（推定：コードから逆算）
- 日付: 2026-06-06（v1.0.1 のコミット「ABI14互換のC言語パーサーWASMへ置換し、バイナリ直接読み込み方式でWindowsのパス問題を回避」）

## 背景（Context）

初版（v1.0.0）では、Windows 環境で WASM の読み込みに失敗した（コミット「Windows環境でのWASMロード失敗を解消」）。

## 決定内容（Decision）

- `bin/` に、tree-sitter 本体と、ABI 14 互換の C 言語パーサーの WASM を置く。
- WASM はパスではなく、バイナリとして読み込んで渡す。

## 理由と検討した代替案（Consequences / Alternatives）

- Windows のパスの扱いによる読み込みの失敗を避けられる（コミットメッセージより）。
- パーサーの WASM は `web-tree-sitter` のバージョン（ABI）と合わせる必要があり、差し替えると初期化に失敗することがある。
- 検討した代替案：パスを指定して読み込む方式（初版）。上記の問題のため変更した。
