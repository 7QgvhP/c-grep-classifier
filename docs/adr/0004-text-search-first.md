# 0004. 出現位置はテキスト検索で列挙し、後から AST で分類する

- ステータス: Accepted
- 日付: TODO(要確認)（記録から特定できない）

## 背景（Context）

AST の識別子ノードを起点に検索すると、型名・数値定数・ラベル・コメントなど、識別子でない出現を取りこぼしたり、件数が VS Code 標準の検索と食い違ったりする。

## 決定内容（Decision）

出現位置は、ファイル本文に対するテキスト検索で列挙する（部分一致は `indexOf`、単語全体一致は正規表現）。各位置について、その位置を含む最小の AST ノードを特定してから分類する。分類できない箇所は「その他」にする。

## 理由と検討した代替案（Consequences / Alternatives）

- 取りこぼしがなく、重複もない（出現位置1件につき結果1件）。対象と除外をそろえれば、件数が VS Code 標準の検索と一致する（[spec.md](../spec.md#補足-検索結果の網羅性)）。
