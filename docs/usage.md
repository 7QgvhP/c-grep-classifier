# 使用方法

記載したコマンドのうち、`npm` のコマンドは 2026-11-15 に実行して動作を確認した。
`code --install-extension` は、手元の VS Code に拡張機能をインストールするため実行しておらず「未検証」としている。画面の操作は、コードと旧 README から読み取った手順で、実機では確認していない。

## 前提条件

- VS Code 1.75.0 以降。

## インストール

[GitHub Releases](https://github.com/7QgvhP/c-grep-classifier/releases) から vsix をダウンロードし、次のコマンドでインストールする（未検証）。

```bash
code --install-extension c-grep-classifier-X.Y.Z.vsix
```

VS Code の拡張機能ビューの「…」→「VSIX からのインストール」でもインストールできる。

## 基本的な使い方

1. アクティビティバーの「C-Grep Classifier」アイコンをクリックする。
2. 検索窓にキーワードを入力し、Enter を押す。
3. カテゴリごとに分類された結果が表示される。項目をクリック、または `↑` `↓` キーで選択すると、該当箇所へジャンプする。

| 操作 | キー |
|---|---|
| 選択テキストで検索 / サイドバーへフォーカス | `Alt + Q` |
| 検索の実行 | Enter（検索窓） |
| 一致箇所の巡回 | `↑` `↓` |
| エディタへフォーカスを移す | Enter（結果リスト） |

## ユースケース別の手順

### エディタで選択した単語で検索する
単語を選択した状態で `Alt + Q` を押す（コマンドパレットの「C-Grep: データフロー分類検索を実行」でも同じ）。

### 部分一致を避ける
検索窓の右の「単語全体に一致」トグルを ON にする（例: `hoge` で `hoge_max` をヒットさせない）。

### 検索結果をエディタのタブで一覧にする
検索窓の右の「検索結果をエディタで開く」ボタン、またはコマンド「C-Grep: 検索結果をエディタで開く」を実行する。結果行で Enter または Ctrl + クリックで該当箇所へジャンプする。

### 変数を書き換えている関数を洗い出す
検索窓の「関数名一覧を表示」トグル、またはコマンド「C-Grep: 関数名一覧の表示を切り替え」で、関数名だけの一覧に切り替える。「出力」の下に並ぶ関数が、その変数を書き換えている関数。

### 分類をさらに細かく見る
設定 `cGrepClassifier.detailLevel` を `detailed` にする（[configuration.md](configuration.md)）。「入力」が条件判定・代入の右辺・初期化値・関数引数・戻り値などに、「出力」が代入・インクリメント・アドレス渡しに分かれる。

### `.inc` などの独自の拡張子も検索する
設定 `cGrepClassifier.includePattern` を変更する（例: `**/*.{c,h,inc}`）。

## よくあるエラーと対処

| 症状 | 原因と対処 |
|---|---|
| 「ワークスペースが開かれていません。」と出る | フォルダを開いてから検索する |
| 「Parserの初期化に失敗しました。…」と出る | `bin/` の WASM が読み込めていない。拡張機能を入れ直す |
| 日本語が文字化けして一致しない | `files.encoding` が実際の文字コードと合っていない。ワークスペースまたは言語ごとの `files.encoding` を設定する |
| VS Code の検索と件数が違う | 対象・除外のファイルが違う。`cGrepClassifier.includePattern`、`excludePatterns`、`useDefaultExcludes` を確認する |
| 関数名一覧で、件数より関数が少ない | 関数に属さない一致（グローバル変数の宣言・マクロ定義など）は、一覧に現れない（件数には含まれる） |
